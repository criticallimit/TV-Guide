# TV Guide

Nach der Installation kann **TV Guide** über den Home-Assistant-Ingress geöffnet werden.

## Konfiguration

- **Standardansicht**: Jetzt, 20:15 oder 22:00
- **Spalten am Desktop**: 3 bis 6

Version 0.1.0 verwendet noch Demo-Programmdaten. Eine echte XMLTV/EPG-Datenquelle wird im nächsten Entwicklungsschritt angebunden.
