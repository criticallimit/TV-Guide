# TV Guide for Home Assistant

Home-Assistant-App/Add-on mit Ingress-Oberfläche für eine kompakte Fernsehzeitschrift.

## Installation

1. Home Assistant öffnen.
2. Einstellungen → Apps/Add-ons → App-/Add-on-Store.
3. Repositories öffnen.
4. `https://github.com/criticallimit/TV-Guide` hinzufügen.
5. **TV Guide** installieren und starten.
6. **In Seitenleiste anzeigen** aktivieren.

## Stand

Version 0.1.0 ist ein UI-Prototyp mit Demo-Programmdaten. Die EPG/XMLTV-Anbindung folgt als nächster Schritt.
